# AWS E-Commerce Data Platform

An end-to-end AWS data engineering project for ingesting, processing, and analyzing e-commerce data.

## Planned Architecture

REST API and CSV files → Amazon S3 Raw → AWS Lambda → AWS Glue and PySpark → S3 Clean and Curated → Glue Data Catalog → Amazon Athena

## Technologies

- Python
- Git and GitHub
- AWS CLI
- Amazon S3
- AWS Lambda
- AWS Glue
- PySpark
- Amazon Athena
- CloudWatch
